-- ToDoFlex --
Aplicación desarrollada en Flutter

Consiste en una aplicación móvil Android nativa, diseñada para gestionar tareas personales de manera intuitiva, rápida y sin necesidad de conexión a internet

ToDoFlex surge ante la necesidad de una herramienta que permita organizar actividades diarias de forma práctica. Su objetivo es mejorar la productividad mediante funciones como la creación, edición, visualización, eliminación y filtrado de tareas, además de la opción de marcarlas como completadas. La aplicación permite gestionar pendientes según categorías, prioridades y fechas límite, incluso cuando el usuario no tiene acceso a una red.
